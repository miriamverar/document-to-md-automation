Document to Markdown Converter
Script de automatización en Python diseñado para procesar y convertir documentos en formato PDF y Microsoft Word a archivos estructurados en MD

Características
- Detección y filtrado automático de archivos compatibles en el directorio de trabajo.
- Conversión rápida de documentos manteniendo estructura de texto.
- Manejo de excepciones y reportes de estado en consola.
